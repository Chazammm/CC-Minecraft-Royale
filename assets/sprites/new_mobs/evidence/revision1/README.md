# Preserved first art pass

These files are exact copies of the shipped exports, terminal capture and native
Lua data at commit `22952924d1dceed8e01c85d63ed3fd7780229946`:

- `love2d/*.png` ← the five corresponding game export PNGs.
- `pixelbox_lua52.json` ← `evidence/pixelbox_lua52.json`.
- `native_sprites.lua` ← `cc_tweaked/sprites.lua`.

They are historical comparison inputs, not current game assets or approved art.
The validator compares each file to its original Git object. The current
`revision_comparison.png` is composed from these real first-pass files and the
current real files at identical pixel magnification, without repainting either.
The original full-size design sources remain available in Git and are not
copied here again.
